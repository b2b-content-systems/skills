# B2B Content Systems skills for Claude Code

Claude skills and tools by [Bryan Bartlett](https://bryanbartlett.com) (B2B Content Systems). Add them all at once:

```
/plugin marketplace add b2b-content-systems/skills
```

Then install the one you want:

| Skill | What it does | Install | Status |
|---|---|---|---|
| [**CHATCOM**](https://github.com/b2b-content-systems/chatcom) | Turn your group chat into your favorite TV series | `/plugin install chatcom@b2b-content-systems` | v0.1 in development |

Every skill here is MIT-licensed, runs on your own computer with your own keys, and says what it sends where before it sends it.
